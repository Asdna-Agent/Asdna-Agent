51 comandos documentados
01

APIs, credenciais e modelos

⌘
/provedores

Lista os provedores de IA pré-configurados e indica o ativo.

/provedor horde

Seleciona a AI Horde, provedor padrão do app.

/provedor blockrun

Ativa o BlockRun; catálogo de modelos gratuitos é filtrado no aplicativo.

/provedor llmfaucet

Ativa o gateway llmfaucet. O catálogo pode usar seletores automáticos.

/provedor openai

Seleciona o perfil OpenAI; pode exigir credencial e cobrança.

/provedor NOME

Troca para outros perfis, incluindo gemini, kilo, groq, deepseek, openrouter, ollama e compativel.

/models

Consulta e lista os modelos da API ativa. Alias: /modelos.

/modelo 1

Seleciona o modelo pelo número mostrado em /models.

/modelo NOME_DO_MODELO

Seleciona por ID exato, quando suportado.

/atualizar

Atualiza o catálogo de modelos do provedor em uso.

/api-testar

Verifica o acesso ao catálogo da API ativa; não garante sucesso da conversa.

/api-chave

Solicita e armazena a chave do provedor ativo com DPAPI no Windows. Alias: /chave.

/api-chave limpar

Remove a chave armazenada do provedor atual (não revoga no serviço).

/api-url https://servidor.example/v1

Configura outro endpoint compatível, via HTTPS ou HTTP local.

/anonimo

Restaura a chave pública anônima da Horde; primeiro ative /provedor horde.

/tokens 2048

Ajusta o tamanho máximo de geração (48 a 8192, limitado pelo provedor).

02

Agente e automação

▣
/agente

Consulta se o modo de execução automática de tarefas está ativo.

/agente on

Ativa o uso automático do agente para pedidos de ações.

/agente off

Desativa o roteamento automático; /pc ainda funciona manualmente.

/pc crie uma pasta chamada exemplo

Força uma tarefa de agente mesmo com o modo automático desligado.

/plano

Mostra planejamento, andamento e evidências da tarefa registrada.

/abrir steam

Localiza e tenta abrir um aplicativo pelo nome ou abreviação.

/apps chrome

Procura aplicativos instalados por trecho do nome.

/perfis chrome

Lista perfis de navegador disponíveis para descoberta.

/janelas

Lista janelas abertas identificadas pelas ferramentas locais.

03

Model Context Protocol

◇
/mcp

Mostra o estado das integrações MCP. Mesmo efeito de /mcp status.

/mcp status

Lista os servidores MCP configurados e seu estado.

/mcp auto on

Ativa a preparação de MCPs conhecidos sob demanda, mediante autorização.

/mcp auto off

Desativa o preparo automático dos MCPs.

/mcp instalar todos

Baixa e configura Filesystem, Playwright e Windows MCP após consentimento.

/mcp instalar filesystem

Instala apenas o servidor Filesystem MCP.

/mcp instalar playwright

Instala apenas o servidor Playwright MCP.

/mcp instalar windows

Instala apenas o servidor Windows MCP.

/mcp ferramentas filesystem

Lista as ferramentas reais do servidor Filesystem MCP.

/mcp ferramentas playwright

Lista as ferramentas reais do servidor Playwright MCP.

/mcp ferramentas windows

Lista as ferramentas reais do servidor Windows MCP. Alias: /mcp tools windows.

/mcp config

Exibe o local do arquivo de configuração dos servidores MCP.

04

Arquivos, projetos e conversa

▤
/colar

Inicia o modo para colar textos e códigos com várias linhas.

/fim

Encerra a entrada iniciada com /colar (não é comando independente).

/historico

Exibe mensagens recentes salvas no histórico local.

/novo

Inicia uma conversa nova e arquiva o histórico anterior.

/salvar codigo.py

Salva o último bloco de código da resposta da IA em um arquivo.

/zip

Compacta o último projeto na pasta Downloads.

/zip PASTA

Compacta uma pasta indicada pelo usuário.

/arquivos

Exibe a localização dos arquivos criados pelo agente.

/arquivos abrir

Abre essa pasta no Explorador do Windows.

/pasta

Mostra a pasta local de configuração, histórico e preferências.

05

Sistema e ajuda

⚙
/ajuda

Mostra a ajuda de comandos dentro do aplicativo. Alias: /help.

/go

Consulta o status do compilador Go disponível no computador.

/instalar-go

Inicia o fluxo de instalação do Go, com autorização quando necessário.

/sair
