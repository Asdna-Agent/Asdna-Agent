COMECE A PROGRAMAR

Compile a sua
versão.

Instale Go no computador, extraia o ZIP de código-fonte, abra a pasta raiz no VS Code e execute o comando a seguir no terminal.

Para apenas usar o executável pronto, não é preciso instalar Go.

PEGAR CÓDIGO-FONTE ↗
POWERSHELL / GO BUILD
$ go build -trimpath -o ASDNA_Horde_Agentes.exe ./cmd/asdna-horde

O comando em uma linha também está disponível no botão COPIAR. No Windows, você pode executar build.bat na raiz.

FAQ / DESENVOLVEDORES

Perguntas frequentes.

Preciso de uma chave de API para começar?+

Não para iniciar com AI Horde: o aplicativo usa uma chave pública anônima. Outros serviços podem exigir autenticação e cobrar pelo uso.

Posso usar qualquer modelo de IA?+

Depende do suporte da API e do modelo. O aplicativo reconhece provedores e endpoints compatíveis, mas chamadas nativas de ferramentas e catálogos variam entre serviços.

As ferramentas MCP funcionam automaticamente?+

Os servidores conhecidos podem ser instalados ou preparados sob demanda, com autorização. A disponibilidade depende do sistema, das dependências e das permissões concedidas.

Onde ficam as configurações locais?+

No Windows, o aplicativo utiliza %APPDATA%\ASDNA_Code_Horde_v1. Use /pasta para localizar a pasta.
