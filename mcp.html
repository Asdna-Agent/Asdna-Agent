TRÊS INTEGRAÇÕES CONHECIDAS

Ferramentas
que ampliam o agente.

Um modelo não controla o computador sozinho. Ações reais dependem dos MCPs conectados, das permissões e do resultado retornado pelas ferramentas.

MCP_01◫

Filesystem

Ler, criar, modificar e organizar arquivos nas pastas autorizadas para o servidor.

/mcp ferramentas filesystem
MCP_02↗

Playwright

Automação de páginas web e formulários conforme as ferramentas disponibilizadas pelo navegador.

/mcp ferramentas playwright
MCP_03▣

Windows

Interação com janelas e componentes de aplicativos, dentro das permissões existentes.

/mcp ferramentas windows

PREPARAR INTEGRAÇÕES

Descubra os MCPs
disponíveis.

Os servidores conhecidos podem ser preparados sob demanda, mediante autorização. Verifique o status e veja as ferramentas antes de iniciar tarefas.

EXEMPLO / MCP
$ /mcp status
$ /mcp instalar todos
$ /mcp ferramentas filesystem
!

Ferramentas precisam de limites claros.

Executar arquivos, abrir aplicativos ou interagir com páginas pode afetar seu computador. Use apenas servidores confiáveis, revise as permissões e mantenha confirmações para operações sensíveis.
